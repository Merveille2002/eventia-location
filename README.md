# Eventia Location — démarrage

Prérequis : Node.js 20+ et MongoDB local.

1. Dans chaque dossier de service : `npm install`, copier `.env.example` vers `.env`, puis `npm start`.
2. Démarrer les services sur les ports 4001 à 4004.
3. Dans `frontend` : `npm install`, puis `npm run dev`.

Le frontend est fourni et ne doit pas être modifié dans la version étudiante.
